# 3Ts and Activities - University Student Success Guide
A modern Arabic website designed to guide university students on developing essential 21st-century skills through Training, Volunteering, Self-Learning, and Student Activities.

## Description
This project is a responsive, RTL Arabic single-page web application tailored for university students. It helps students understand and apply the "3 Ts and Activities" framework, which focuses on training (internships), volunteering, self-learning (online courses), and meaningful student activities to build employable skills and prepare for the job market.

Using clear examples, interactive sections, and actionable advice, the website motivates students to proactively develop themselves during their academic years.

## Features
- Clean modern design with Arabic RTL support
- Interactive CV comparison (Basic vs Advanced)
- Detailed explanations for each of the 3 Ts with examples
- Student activities section with selection criteria
- Action plan checklist to help students track progress
- Resources section with curated external links
- Mobile responsive and accessible design
- Smooth scrolling navigation and animations
